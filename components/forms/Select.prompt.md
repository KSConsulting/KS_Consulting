Dropdown matched to Input's box. Use for short, known lists (budget range, segment, number of employees).

```jsx
<Select label="Investimento mensal" options={["Até R$ 5 mil", "R$ 5–20 mil", "Acima de R$ 20 mil"]} />
```

Chevron is drawn with a rotated border, not an icon font, so it needs no CDN.
